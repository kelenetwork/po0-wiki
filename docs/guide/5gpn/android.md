# Android 接入：私人 DNS

Android（9+）通过系统「私人 DNS」接入，**无需安装任何应用**。

## 原理

Android 只提供「私人 DNS」一个系统级入口，网关据此完成分流：

- 国内域名 / GEOIP 命中 → 返回真实 IP → **手机本地直连**
- 国外域名 → A 记录改写为网关 IP → 网关嗅探 SNI 后按当前出口转发
- WhatsApp 等无 SNI 私有协议 → 由 DNS 线索回退兜底

## 设置步骤

1. 打开 **设置 → 网络和互联网 → 私人 DNS**
   （部分品牌路径为 设置 → 连接与共享 → 私人 DNS）
2. 选择「**指定的私人 DNS 服务提供商主机名**」
3. 填入你的网关域名（如 `gw.example.com`），保存

立即生效，无需重启。

## 验证是否生效

使用 5GPN 卡的蜂窝数据：

- 打开 `ip.cn` → 应显示运营商出口（国内本地直连）
- 打开 YouTube → 应正常访问（走网关国外出口）

## 已知取舍

- 网关数据面为 IPv4-only：客户端的 AAAA 查询返回空，仅发布 IPv6 的极少数站点不可达（明确接受的取舍）
- QUIC（UDP 443）会被拒绝，促使应用快速回落 TCP，属预期行为
- 若某国内 App 判定异常，可在 Bot / 面板加一条 `direct` 规则精确修正

## 常见问题

**填了私人 DNS 后无法上网？**
先确认手机正在使用已绑定的 5GPN 卡蜂窝数据；网关的 853 端口只对内网卡网段开放，其他网络（含家庭 Wi-Fi）连不上私人 DNS 属正常。Wi-Fi 下建议把私人 DNS 切回「自动」，或使用支持按网络自动切换的系统特性。
