# 连通诊断与常见问题

## 逐层诊断

遇到「某个网站打不开」，先检查策略、出口、连接和应用层，不要盲目改配置。

**Telegram Bot**：连通诊断 → 输入域名或完整 URL。

**命令行**：

```bash
5gpnd probe -c /etc/5gpn-next/config.json youtube.com
```

正常输出类似：

```text
[1] 入口   probe 本地发起                           ✓   0.0ms
[2] 策略   FINAL → 国外默认出口                    ✓   0.1ms
[3] 出口   当前出口可用                            ✓   0.0ms
[4] 连接   TCP 目标:443 已建立                     ✓  59.6ms
[5] 应用   TLS 证书校验通过                        ✓ 109.9ms
结论：正常（总计 169.7ms）
```

任何一层失败都会显示具体原因。

## 常见问题

### 可以用其他厂商的 VPS 吗？

暂时不行。5GPN 内网卡流量只会送达 KFCHOST 网段，网关必须部署在 KFC 机器上。

### 移动、电信或其他省份的联通卡可以吗？

目前仅支持**浙江联通卡**，需要自行办理并在 KFCHOST 控制台完成绑定。

### iPhone 安装描述文件后会影响 Wi-Fi 吗？

不会。当前 iOS 描述文件只在蜂窝数据下启用加密 DNS，连接 Wi-Fi 后自动停用，家庭或公司网络不经过网关。

### Android 连 Wi-Fi 后提示“私人 DNS 无法访问”？

Android 私人 DNS 是系统级设置，也会应用到 Wi-Fi。如果当前 Wi-Fi 无法访问网关 853 端口，请暂时切回「自动」；回到 5GPN 蜂窝网络后再恢复指定主机名。

### 广告拦截显示已开启，但规则数为 0？

再次点击「开启拦截」。v0.13.1 起会重新下载规则并热重载，无需先关闭。如果仍失败，请检查网关能否访问 `anti-ad.net`，再查看：

```bash
journalctl -u 5gpn-next -n 100 --no-pager
```

### 开启广告拦截后某个 App 白屏？

打开 Bot 或 Web 的「最近命中」，找到该 App 使用的可疑域名并加入白名单。白名单会放行该域名及其子域。

DNS 层无法处理 App 自带 DoH / DoQ、直接访问 IP 的广告，以及与正常业务共用同一域名的原生广告。

### WhatsApp 官网能开，但聊天连不上？

部分私有协议没有 SNI 或 HTTP Host。网关会尝试用近期 DNS 线索还原目标，但无法可靠关联时仍可能失败。

先运行连通诊断并切换可用代理出口。如果已确认是 Meta 网段，也可以添加精确规则：

```text
IP-CIDR,31.13.0.0/16,proxy:节点名
IP-CIDR,66.220.144.0/20,proxy:节点名
IP-CIDR,69.63.176.0/20,proxy:节点名
IP-CIDR,157.240.0.0/16,proxy:节点名
```

### 切换国外出口后，国内流量也会改变吗？

不会。国内域名或 GEOIP CN 命中后，DoT 返回真实 IP，由手机本地蜂窝网络直连。国外默认出口只处理 FINAL 未命中的其余流量。

### 某个国内 App 变慢？

先执行 `probe` 查看域名或目标 IP 的判定，再添加更具体的 `direct` 规则。用户规则优先于广告规则和国内兜底。

### 国外网站全部打不开？

运行：

```bash
5gpnd probe -c /etc/5gpn-next/config.json youtube.com
```

若当前为 KFC 本机出口，目标可能不接受该公网线路；添加落地节点并切换后重试。

### 描述文件链接或面板打不开？

两者只允许 `client_cidr` 来源。请关闭 Wi-Fi，确认手机正在使用已绑定的 5GPN 卡蜂窝数据，并检查 nftables 与云厂商安全组。

### 服务器升级后需要重装描述文件吗？

从 v0.13.0 起，一般不需要。只有从 v0.12.5 或更早版本首次升级时，需要删除旧描述文件、重新安装当前蜂窝 DNS 描述文件，并确认系统中没有遗留的 `5gpn-NEXT` 根证书。

### 网关故障时怎么临时恢复联网？

- iPhone：连接正常 Wi-Fi，蜂窝 DNS 描述文件会自动停用
- Android：把私人 DNS 切回「自动」

恢复网关后，再按对应平台的正常接入方式启用。

### 它会修改手机定位或解密 HTTPS 吗？

不会。当前版本不读取或改写系统位置，不生成根证书，也不做 TLS 中间人解密。

## 反馈问题时请附上

1. `5gpnd version`
2. `5gpnd probe -c /etc/5gpn-next/config.json <目标>` 的完整输出
3. 平台：iOS 蜂窝 DNS或 Android 私人 DNS
4. 当前国外默认出口
5. `journalctl -u 5gpn-next -n 100 --no-pager` 中与故障时间对应的日志

请先删除日志中的域名、节点地址或其他不愿公开的信息，再发到公开 Issue。
