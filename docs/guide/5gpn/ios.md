# iOS 接入：两种模式二选一

iPhone / iPad（iOS 17+）通过安装一张系统描述文件接入，有两种模式，**不可同时安装**，切换前先删除旧的 5gpn 描述文件。

## 📡 蜂窝 DNS 模式（推荐日常使用）

仅蜂窝数据下启用加密 DNS（DoT 指向网关）；**连上 Wi-Fi 自动停用，家庭/公司网络完全不经过网关**。

- 国内域名 / GEOIP 命中 → 返回真实 IP → 手机本地直连
- 国外域名 → 由网关按当前出口分流
- WhatsApp 等无 SNI 私有协议：由 DNS 线索回退支持

## 🔗 Relay 模式（实验性，谨慎使用）

iOS 原生 Network Relay，客户端在连接时主动携带目的地，TCP 协议覆盖最完整。但目前存在多个**结构性限制**，日常使用请优先选蜂窝 DNS 模式：

- ⚠️ **蜂窝与 Wi-Fi 同时生效**，无法按接口设置「仅蜂窝启用」。连家里 Wi-Fi 时会**覆盖路由器/软路由的分流策略**，未入直连名单的国内域名也会绕行网关，部分国内站点变慢甚至不可达
- ⚠️ **UDP/QUIC 未支持**：抖音、TikTok 等短视频 App 大量使用 QUIC，可能出现刷不出下一条视频的卡顿
- ⚠️ **WhatsApp 可能不可用**：蜂窝 IPv6 环境下 WhatsApp 优先连 Meta 的 IPv6 字面量，而网关出口无 IPv6 能力，无论切哪个出口都无法建连；蜂窝 DNS 模式不受影响（AAAA 置空，强制走 IPv4）
- iOS 26+ 可在系统设置中手动关闭 Relay；旧版系统只能停用/移除描述文件
- 描述文件内置国内直连名单，常用国内 App 不进入 Relay

## 模式对比

| | 📡 蜂窝 DNS（推荐） | 🔗 Relay（实验性） |
| :-- | :-- | :-- |
| Wi-Fi 影响 | 无，自动停用 | 蜂窝/Wi-Fi 同时生效，会覆盖家内分流 |
| 国内流量 | GEOIP 手机本地直连 | 仅名单内本地直连，其余绕网关 |
| UDP / QUIC | 拒绝后回落 TCP | 未支持，短视频 App 可能卡顿 |
| WhatsApp | 支持（AAAA 置空走 IPv4 + 线索回退） | IPv6 环境下可能不可用 |
| 适合 | 日常使用（默认选这个） | 特定 TCP 协议场景 |

## 安装步骤

1. 在 Telegram Bot →「客户端接入」中选择模式获取描述文件；或使用内网卡蜂窝数据在 Safari 打开安装脚本输出的下载链接
2. 打开 **设置 → 通用 → VPN 与设备管理**
3. 安装「5gpn-NEXT」描述文件

> 切换模式时：先在「VPN 与设备管理」里删除旧的 5gpn 描述文件，再安装新模式的文件。

## 验证是否生效

蜂窝数据下：

- 打开 `ip.cn` → 应显示你的运营商出口（国内本地直连）
- 打开 YouTube → 应正常访问（走网关国外出口）

蜂窝 DNS 模式下连上 Wi-Fi 后，一切流量走 Wi-Fi 本身，与网关无关。
