# iOS 接入：两种模式二选一

iPhone / iPad（iOS 17+）通过安装一张系统描述文件接入，有两种模式，**不可同时安装**，切换前先删除旧的 5gpn 描述文件。

## 📡 蜂窝 DNS 模式（推荐日常使用）

仅蜂窝数据下启用加密 DNS（DoT 指向网关）；**连上 Wi-Fi 自动停用，家庭/公司网络完全不经过网关**。

- 国内域名 / GEOIP 命中 → 返回真实 IP → 手机本地直连
- 国外域名 → 由网关按当前出口分流
- WhatsApp 等无 SNI 私有协议：由 DNS 线索回退支持

## 🔗 Relay 模式（协议兼容优先）

iOS 原生 Network Relay，客户端在连接时主动携带目的地，协议覆盖最完整（含全部无 SNI 私有协议）。

- ⚠️ 系统级配置，**蜂窝与 Wi-Fi 同时生效**，无法按接口设置「仅蜂窝启用」
- iOS 26+ 可在系统设置中手动关闭 Relay；旧版系统只能停用/移除描述文件
- 描述文件内置国内直连名单，常用国内 App 不进入 Relay

## 模式对比

| | 📡 蜂窝 DNS | 🔗 Relay |
| :-- | :-- | :-- |
| Wi-Fi 影响 | 无，自动停用 | 蜂窝/Wi-Fi 同时生效 |
| 国内流量 | GEOIP 手机本地直连 | 名单内本地直连，其余绕网关 |
| 协议覆盖 | HTTPS/SNI + DNS 线索回退 | 完整（含无 SNI 协议） |
| WhatsApp | 支持（线索回退） | 原生支持 |
| 适合 | 日常使用 | 协议兼容性优先 |

## 安装步骤

1. 在 Telegram Bot →「客户端接入」中选择模式获取描述文件；或使用内网卡蜂窝数据在 Safari 打开安装脚本输出的下载链接
2. 打开 **设置 → 通用 → VPN 与设备管理**
3. 安装「5gpn-NEXT」描述文件

> 切换模式时：先在「VPN 与设备管理」里删除旧的 5gpn 描述文件，再安装新模式的文件。

## 验证是否生效

蜂窝数据下：

- 打开 `ip.cn` → 应显示你的运营商出口（国内本地直连）
- 打开 YouTube → 应正常访问（走网关国外出口）

蜂窝 DNS 模式下连上 Wi-Fi 后，一切流量走 Wi-Fi 本身，与网关无关。
