# 准备工作

部署前请逐项确认以下条件，任何一项不满足都无法完成接入。

## 1. KFCHOST 机器（必须）

网关**只能部署在 KFCHOST 的机器 / 网段上**：5GPN 内网卡的流量由运营商定向送达 KFC 的网段，其他厂商的 VPS 收不到内网卡流量，目前不可用。

配置要求很低：

| 项目 | 最低要求 | 建议 |
| :-- | :-- | :-- |
| 系统 | Debian 12+ / Ubuntu 22.04+ | Debian 12 |
| 内存 | 512 MB | 1 GB |
| 架构 | amd64 / arm64 | — |

网关本体是单个 Go 二进制，常驻内存约 26 MB。

## 2. 浙江联通 5GPN 卡（必须，自行办理）

- 目前**仅支持浙江联通**的卡，其他运营商与省份暂不可用
- 需要**自行办理**，办好后在 KFCHOST 控制台完成绑定
- 绑定成功后，手机使用这张卡的蜂窝数据即可走内网链路到达你的网关

## 3. 自有域名（必须）

- 用于向 Let's Encrypt 签发 TLS 证书（iOS 描述文件与 DoT 都要求可信证书）
- 需要能自行修改 DNS 解析记录：安装前把域名 A 记录指向 KFC 机器的公网 IP
- 使用 Cloudflare 时请选择「仅 DNS」（灰云）：橙云代理不覆盖非标准端口

## 4. 落地节点（可选）

如果国外流量希望走其他出口（而不是 KFC 机器本机公网 IP 直出），准备一条节点分享链接即可，支持：

```text
ss:// vless:// vmess:// trojan:// hysteria2:// tuic:// socks5:// http://
```

安装时粘贴，或装完后随时在 Telegram Bot / 面板里添加，支持多出口热切换。

## 5. Telegram Bot（可选，推荐）

准备一个 Bot Token（找 @BotFather 创建）和你的 Telegram 数字 ID，即可在聊天窗口完成日常管理：切换出口、改分流规则、逐层诊断、一键升级。
